# BÉ LAN PDF EDITOR

Ứng dụng web tĩnh để sắp xếp, xoá, xoay và gộp các trang PDF trực tiếp trong trình duyệt.

## Đưa lên GitHub Pages

1. Đẩy toàn bộ thư mục này lên một repository GitHub.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)` rồi nhấn **Save**.

Không cần build. Mở `index.html` trực tiếp hoặc dùng một static server để chạy cục bộ.
